## What I've Shipped

**🤖 Agentic CI Auto-Tracking System** — First production AI Agent at Cloudzest. Replaced a manual compliance workflow at a Tier-1 banking client with a 5-step agentic flow: classify → validate → fetch → hierarchy → summarise.

**🔗 ServiceNow × Claude MCP Server** *(Open Source)* — Built a **Model Context Protocol server** connecting ServiceNow's REST layer to Claude Desktop before official platform support. Gives a 6–12 month competitive lead with a reusable, documented architecture pattern. See pinned repo below.

**🏗️ ECPro Portal Replacement** — Replicated a licensed third-party product's full functionality within an existing ServiceNow license, eliminating the client 's EC PRO license purchase. End-to-end: architecture, SP widgets, role-based views, responsive grid, dynamic navigation.


**🔬 Discovery Health Reporting System** — Automated health report with ServiceNow data, Now Assist-generated narratives, PDF export with inline severity badges.

**⚙️ GenAI vs Agentic AI Decision Framework** — Built and evangelised internally. Now used in client-facing AI scoping conversations across enterprise accounts. Pitched to 3 clients proactively (manufacturing, financial services, enterprise software).
